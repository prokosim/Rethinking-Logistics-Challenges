title: About the project
---

*Rethinking.Logistics* is a design studio at ARCHIP (Architectural Institute in Prague), led by Lukáš Kurilla and Šimon Prokop. In 2026 students redesigned logistics buildings — warehouses, cross-docks, micro-hubs, data centres and recycling facilities — using a Double Diamond process: research the problem, define ambitions and metrics, then design and test alternatives with evidence.

This knowledge base collects what the studio learned:

- which **design challenges** logistics architecture faces,
- which **metrics** students defined, adapted or adopted (e.g. from BREEAM, LEED, DGNB) to measure them,
- which **tools** can calculate those metrics, and
- how each **case study** used them to make decisions — including the trade-offs and the gaps.

## Sources

- 23 student portfolios (linked from each case study)
- Studio questionnaire *Point AMBITIONS — Peak of the First Diamond*
- Studio questionnaire *Mid-Term Review*
- Tool documentation (links on each tool page)
